
# NANA-PS3

**Proyecto comunitario de adaptación nativa de NANA (PS2) a PlayStation 3.**

## Estado del proyecto

Fase 0 — Foundation & Research.

Este proyecto busca investigar y desarrollar una adaptación nativa para PS3. Todavía no existe un port funcional.

## Objetivos

- Compatibilidad objetivo con PS3 FAT, Slim y Super Slim.
- Soporte objetivo para consolas con HEN y CFW.
- Gráficos y audio adaptados a PS3.
- Controles compatibles con DualShock 3.
- Interfaz y escenas reconstruidas.
- Desarrollo comunitario y código documentado.
