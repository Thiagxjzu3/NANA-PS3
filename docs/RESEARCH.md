
# NANA-PS3 — TECHNICAL RESEARCH

## 1. Objetivo

Investigar los aspectos técnicos necesarios para desarrollar una adaptación nativa de NANA de PS2 a PS3.

## 2. Arquitectura de PlayStation 3

Investigar:

- Procesador Cell Broadband Engine.
- Unidad gráfica RSX.
- Memoria principal y memoria gráfica.
- Sistema de archivos.
- Sistema de entrada.
- Sistema de audio.

## 3. Herramientas

Investigar y documentar:

- PS3DEV.
- PSL1GHT.
- Compilador compatible con PowerPC.
- Herramientas para generar aplicaciones homebrew.
- Herramientas de depuración.

## 4. Investigación del juego original

Pendiente de disponer de una copia legítima del juego y estudiar sus formatos.

No se incluirán archivos originales protegidos en este repositorio.

## 5. Arquitectura propuesta

- Core: inicialización y ciclo principal.
- Graphics: renderizado.
- Audio: reproducción de sonido.
- Input: controles.
- Resources: administración de recursos.
- Scenes: administración de escenas.

## 6. Restricciones

- No se promete conversión automática de PS2 a PS3.
- No se copiarán recursos protegidos sin autorización.
- La compatibilidad se confirmará mediante pruebas reales.
- La primera demo utilizará contenido original.

## 7. Estado

Investigación inicial pendiente.
