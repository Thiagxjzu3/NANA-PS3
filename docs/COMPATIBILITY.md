
# NANA-PS3 — COMPATIBILITY

## Objetivo

Investigar la compatibilidad de la futura aplicación homebrew en distintas consolas PlayStation 3.

## Modelos

| Modelo | Estado |
|---|---|
| PS3 FAT | Pendiente de pruebas |
| PS3 Slim | Pendiente de pruebas |
| PS3 Super Slim | Pendiente de pruebas |

## Entornos

| Entorno | Estado |
|---|---|
| HEN | Pendiente de investigación |
| CFW | Pendiente de investigación |
| Firmware oficial | Sin soporte confirmado |

## Áreas de prueba

- Inicio de la aplicación.
- Renderizado gráfico.
- Audio.
- Controles DualShock 3.
- Memoria disponible.
- Estabilidad.
- Rendimiento.

## Registro de pruebas

Cada prueba deberá incluir:

- Modelo de consola.
- Versión del firmware.
- Versión de HEN o CFW.
- Versión del programa.
- Resultado.
- Errores encontrados.

## Aviso

La compatibilidad todavía no está confirmada. No se garantiza que todos los modelos o firmwares puedan ejecutar la futura aplicación.
