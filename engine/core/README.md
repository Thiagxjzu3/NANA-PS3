
# CORE — NANA-PS3

## Responsabilidad

El módulo Core será el núcleo de la aplicación.

## Funciones previstas

- Inicializar la aplicación.
- Mantener el ciclo principal.
- Administrar los estados del programa.
- Coordinar los demás módulos.
- Gestionar el cierre correcto.

## Ciclo principal previsto

1. Inicialización.
2. Lectura de controles.
3. Actualización de estados.
4. Procesamiento gráfico.
5. Presentación del cuadro.
6. Repetición del ciclo.
