
# NANA-PS3 — ENGINE

Esta carpeta contiene el motor de la futura aplicación homebrew.

## Módulos

- core: inicialización y ciclo principal.
- graphics: renderizado gráfico.
- audio: reproducción de audio.
- input: controles.
- resources: administración de recursos.
- scenes: gestión de escenas.

## Estado

Estructura inicial. Todavía no contiene un motor funcional.

## Principios

- Código modular.
- Funciones reales, no simuladas.
- Compatibilidad documentada.
- Pruebas progresivas en hardware.
- Contenido original o autorizado.
